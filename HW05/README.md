# Мини-маркет

Домашняя работа №5 по React.

Мини-маркет представляет собой каталог товаров с возможностью поиска, фильтрации, добавления товаров в корзину и переключения цветовой темы.

## Используемые технологии

- React
- TypeScript
- Vite
- styled-components
- Vitest
- React Testing Library

## Функциональность

- Светлая, тёмная и розовая темы.
- Сохранение выбранной темы в localStorage.
- Поддержка системной цветовой темы.
- UI-кит: Button, Badge, Card, Input, Grid.
- Четыре варианта и три размера кнопок.
- Поиск товаров по названию.
- Фильтрация по категориям.
- Добавление товаров в корзину с состоянием загрузки.
- Подсчёт количества и общей стоимости товаров.
- Адаптивная сетка каталога.
- Пустое состояние при отсутствии результатов.
- Скелетоны при загрузке товаров.
- Поддержка клавиатурной навигации.
- Автоматические тесты.

## styled-components против CSS Modules на моём проекте

В этом проекте я использовала styled-components для создания переиспользуемых компонентов и переключения цветовых тем. Мне понравилось, что стили можно описывать непосредственно рядом с компонентами. С помощью ThemeProvider удобно передавать цвета и другие параметры оформления всему приложению. Transient props позволяют изменять внешний вид компонентов, не передавая лишние свойства в DOM. При использовании CSS Modules стили хранились бы в отдельных файлах, а для переключения тем можно было бы использовать CSS-переменные. Недостатком styled-components является дополнительная зависимость и необходимость настройки типизации темы. Для моего мини-маркета styled-components оказались удобным решением благодаря наличию нескольких тем и общего UI-кита.
