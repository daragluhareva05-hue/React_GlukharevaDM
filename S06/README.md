# S06 — Командный трекер задач

Node.js 22.12+ (для Vite 7). Два терминала из папки S06:

```sh
cd api
npm ci
npm start
```

```sh
cd client
npm install
npm run dev
```

Открыть адрес Vite (обычно http://localhost:5173). API работает на http://localhost:3001. Для проверки сборки: `npm run build` в client. После первого npm install сохранить client/package-lock.json в Git.

## Где хранятся данные

- usersSlice: участники, статус, ошибка, requestId. Собственный middleware вызывает fetch, проверяет response.ok, отправляет lifecycle actions, предотвращает дубли. Selectors выбирают список и участника.
- uiSlice: ID избранных участников без дублей; selectors списка и счётчика. Избранное хранится до перезагрузки (сохранение между сессиями — дополнительное задание).
- tasksApi: RTK Query хранит ответы и состояния запросов, генерирует hooks, управляет подписками, кэшем и инвалидацией Task/LIST и Task/id. Отдельного tasksSlice нет.
- URL: userId, taskId и status; локальное состояние React: поля форм.
- API: data/db.json, создаётся из seed.json при первом запуске. Для сброса остановить API и удалить data/db.json.

## Проверка на защите

1. Открыть напрямую /users/1/tasks и обновить страницу.
2. Добавить участника в избранное, проверить профиль, список и счётчик.
3. Создать задачу, открыть её, изменить название и статус, удалить; проверить сохранение после обновления.
4. Сменить фильтр и нажать Back/Forward.
5. Повторно открыть список в течение 60 секунд, проверить Network и Redux DevTools.
6. Остановить API, обновить список или сохранить задачу; запустить API и повторить. Для проверки users middleware обновить страницу при остановленном API.
7. Проверить /unknown, /users/999, /tasks/999 и пустое название.
8. Проверить lazy-загрузку TaskPage в Network.
