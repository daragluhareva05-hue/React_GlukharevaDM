# API команды и задач

Локальный API на Node.js и Express для задания со слайда 32 презентации «SPA, Redux Toolkit и RTK Query».

## Запуск

В каталоге проекта выполните команды с Node.js 22 или новее.

```bash
npm ci
npm start
```

Базовый URL для `fetch` и `fetchBaseQuery` — `http://localhost:3001`. CORS включён для запросов из браузера. Порт можно задать через `PORT`, адрес прослушивания — через `HOST`. По умолчанию сервер слушает `127.0.0.1`.

## Маршруты

| Метод и путь | Результат |
| --- | --- |
| `GET /users` | `200`, массив участников с полями `id`, `name`, `email` |
| `GET /tasks?userId=1&status=todo` | `200`, массив задач участника. Параметр `userId` обязателен, `status` можно опустить. При отсутствии совпадений возвращается `[]`. |
| `GET /tasks/:id` | `200`, объект задачи |
| `POST /tasks` | `201`, созданная задача и заголовок `Location`. В JSON передайте `userId`, `title` и при необходимости `status`. По умолчанию используется `todo`. |
| `PATCH /tasks/:id` | `200`, обновлённая задача. В JSON передайте `title`, `status` или оба поля. |
| `DELETE /tasks/:id` | `204`, пустой ответ |

Задача содержит `id`, `userId`, `title` и `status`. Все ID — строки. Допустимые статусы — `todo`, `doing`, `done`. Начальные и конечные пробелы в названии удаляются. Ошибки возвращаются в формате `{"message":"…"}`. Код `400` означает ошибку запроса, `404` — неизвестный маршрут, участника или задачу.

```bash
curl 'http://localhost:3001/tasks?userId=1&status=todo'

curl -i 'http://localhost:3001/tasks' \
  -H 'Content-Type: application/json' \
  -d '{"userId":"1","title":"Проверить API","status":"todo"}'
```

## Данные

При первом запуске сервер создаёт `data/db.json` на основе `src/seed.json` с четырьмя участниками и восемью задачами. Сервер записывает изменения задач в файл до отправки ответа. После перезапуска он читает тот же файл. Путь можно переопределить через `DATA_FILE`. Для отдельного набора данных укажите новый путь. Каждый файл рассчитан на один процесс API.
